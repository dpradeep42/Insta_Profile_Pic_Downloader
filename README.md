# Insta_Profile_Pic_Downloader

A small Python script that downloads the profile picture of an Instagram account. It prompts for a username and calls Instaloader's `download_profile` with `profile_pic_only=True`; the image is saved into a folder named after the profile.

## Tech stack

- Python 3
- Instaloader

## How to run

```bash
pip install instaloader
python main.py
```
